# Univer 라이브러리 문제 원인 및 해결 가이드

## 🔍 문제 분석

### 1. CDN 및 버전 문제
**문제점:**
- 잘못된 CDN 링크 사용
- 버전 불일치로 인한 호환성 문제
- UMD 빌드 파일 경로 오류

**원인:**
```html
<!-- 잘못된 방식 -->
<script src="https://unpkg.com/@univerjs/presets@0.10.8/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs/preset-sheets-ui@0.10.8/lib/umd/index.js"></script>
```

**해결:**
```html
<!-- 올바른 방식 -->
<script src="https://unpkg.com/@univerjs/presets/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs/preset-sheets-core/lib/umd/index.js"></script>
```

### 2. 전역 네임스페이스 문제
**문제점:**
- `window.UniverSheetsUi` 등이 undefined
- 잘못된 전역 객체 참조

**원인:**
```javascript
// 잘못된 방식
const { UniverSheetsUIPlugin } = window.UniverSheetsUi; // undefined
```

**해결:**
```javascript
// 올바른 방식 - Core Preset만 사용
const { createUniver } = window.UniverPresets;
const { UniverSheetsCorePreset } = window.UniverPresetSheetsCore;
```

### 3. 초기화 복잡성 문제
**문제점:**
- 과도하게 복잡한 초기화 코드
- 불필요한 플러그인 등록 시도
- Selection API 관련 복잡한 처리

**원인:**
```javascript
// 복잡하고 불안정한 방식
// Selection API 타이밍 문제 해결 시도
// UI 플러그인 수동 등록
// 복잡한 오류 처리
```

**해결:**
```javascript
// 간단하고 안정적인 방식
const result = createUniver({
    locale: 'en-US',
    locales: localeEnUS ? { 'en-US': localeEnUS } : {},
    presets: [
        UniverSheetsCorePreset({
            container: container
        })
    ]
});
```

## ✅ 해결 방법

### 1. 올바른 CDN 링크 사용

```html
<!-- 필수 의존성 -->
<script src="https://unpkg.com/react@18.3.1/umd/react.production.min.js"></script>
<script src="https://unpkg.com/react-dom@18.3.1/umd/react-dom.production.min.js"></script>
<script src="https://unpkg.com/rxjs/dist/bundles/rxjs.umd.min.js"></script>

<!-- Univer Core Presets -->
<script src="https://unpkg.com/@univerjs/presets/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs/preset-sheets-core/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs/preset-sheets-core/lib/umd/locales/en-US.js"></script>

<!-- CSS -->
<link rel="stylesheet" href="https://unpkg.com/@univerjs/preset-sheets-core/lib/index.css" />
```

### 2. 올바른 전역 객체 사용

```javascript
// 필수 객체 확인
if (!window.UniverPresets) {
    throw new Error('UniverPresets가 로드되지 않았습니다');
}

if (!window.UniverPresetSheetsCore) {
    throw new Error('UniverPresetSheetsCore가 로드되지 않았습니다');
}

// 올바른 추출
const { createUniver } = window.UniverPresets;
const { UniverSheetsCorePreset } = window.UniverPresetSheetsCore;
const localeEnUS = window.UniverPresetSheetsCoreEnUS;
```

### 3. 간단한 초기화

```javascript
async function initUniver() {
    try {
        const container = document.getElementById('univer');

        const result = createUniver({
            locale: 'en-US',
            locales: localeEnUS ? { 'en-US': localeEnUS } : {},
            presets: [
                UniverSheetsCorePreset({
                    container: container,
                    header: true,
                    toolbar: true,
                    footer: true
                })
            ]
        });

        univer = result.univer;
        univerAPI = result.univerAPI;

        // 간단한 워크북 생성
        workbook = univerAPI.createWorkbook({
            name: 'Test Workbook',
            sheets: [{
                name: 'Sheet1',
                cellData: {
                    0: { 0: { v: 'Hello' }, 1: { v: 'World' } }
                }
            }]
        });

        console.log('✅ 초기화 완료');

    } catch (error) {
        console.error('❌ 초기화 실패:', error);
    }
}
```

## 📋 현재 기능 제한사항

### 지원하는 기능
- ✅ 기본 스프레드시트 표시
- ✅ 셀 값 입력/편집
- ✅ 간단한 템플릿 로드
- ✅ CSV 형태 데이터 내보내기
- ✅ 워크북/워크시트 생성

### 제한사항
- ❌ Excel 파일 완전한 임포트 (스타일, 수식, 차트 보존)
- ❌ Excel 파일 완전한 익스포트 (스타일, 수식, 차트 보존)
- ❌ 고급 수식 기능
- ❌ 차트 및 그래프
- ❌ 복잡한 스타일링

### 현재 수준
**값-only 임포트/익스포트**: 셀의 텍스트 값만 보존하고 처리

## 📝 결론

**현재 상태**: 값-only 임포트/익스포트가 가능한 기본 스프레드시트 시스템
**문제 해결됨**: CDN, 전역 네임스페이스, 초기화 복잡성 모든 문제 해결
**실제 사용 가능**: 기본적인 스프레드시트 편집 및 템플릿 기능 작동

완전한 Excel 호환성이 필요한 경우, 서버 측 처리나 상용 솔루션 검토 권장.
