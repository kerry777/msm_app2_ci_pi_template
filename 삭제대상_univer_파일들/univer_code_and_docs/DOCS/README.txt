# MSM Excel - Univer Minimal (Fixed) — 빠른 시작
1) HTML에서 스크립트를 **반드시** 다음 순서로 로드하세요. (세 패키지 버전 통일)
   - @univerjs/core → @univerjs/sheets → @univerjs/sheets-ui → (content.js) → index.js
2) `index.js`는 `UniverCore` 네임스페이스만을 사용하여 최소 설정으로 시트/UI를 렌더링합니다.
3) 플러그인을 늘리거나 커맨드 시스템을 붙일 때는 해당 버전 문서의 정확한 네임스페이스를 따르세요.
