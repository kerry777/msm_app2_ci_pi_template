2. 각 솔루션별 상세 분석

🏆 Univer (추천 1순위)

장점:
• Luckysheet의 모든 기능 + 개선된 아키텍처
• 완전한 Excel 서식 지원 (조건부 서식 포함)
• 실시간 협업 편집
• 플러그인 기반 확장 가능
• TypeScript 기반 안정성
• 모바일 최적화
단점:
• 상대적으로 새로운 프로젝트
• 문서화가 아직 부족
• 일부 고급 기능 개발 중
npm install @univerjs/core @univerjs/engine-render npm install @univerjs/sheets @univerjs/sheets-ui

⚡ x-data-spreadsheet

장점:
• 가벼우고 빠름 (100KB 미만)
• 활발한 커뮤니티 (14K+ Stars)
• 안정적인 기본 기능
• 쉬운 통합
• 모바일 친화적
단점:
• 제한적인 Excel 호환성
• 실시간 협업 미지원
• 고급 차트 기능 부족
• 조건부 서식 제한적
npm install x-data-spreadsheet // 기본 사용법 import Spreadsheet from 'x-data-spreadsheet';

🤝 EtherCalc

장점:
• 설치 불필요 (웹 기반)
• 실시간 협업 우수
• 서버 부하 적음
• 간단한 사용법
단점:
• 매우 제한적인 서식 지원
• Excel 호환성 낮음
• 차트 기능 부족
• 기업용으로 부적합
// 웹 기반 - API 호출만 필요 fetch('/ethercalc-api/cells/A1', { method: 'PUT', body: 'Hello World' });

3. MSM 견적서 시스템 적용 시나리오

🎯 시나리오별 권장 솔루션

시나리오 1: 완벽한 Excel 호환성 필요

권장: OnlyOffice Community Edition + Univer
• 기존 Excel 파일 100% 호환
• 모든 서식 보존
• 실시간 협업 지원
• 예상 구현 기간: 6-8주

시나리오 2: 빠른 구현 + 기본 기능

권장: x-data-spreadsheet + ExcelJS
• 빠른 프로토타입 가능
• 기본적인 견적서 기능 충족
• 낮은 서버 부하
• 예상 구현 기간: 2-3주

시나리오 3: 협업 중심 + 단순 기능

권장: EtherCalc + 커스텀 UI
• 실시간 협업 최적화
• 간단한 견적서 작성
• 최소한의 인프라
• 예상 구현 기간: 3-4주

4. 기술적 구현 예제

Univer 통합 예제 (MSM 견적서)

// Univer 초기화 및 MSM 견적서 템플릿 적용 import { Univer, LocaleType } from '@univerjs/core'; import { UniverDocsPlugin } from '@univerjs/docs'; import { UniverSheetsPlugin } from '@univerjs/sheets'; // MSM 견적서 전용 설정 const univerConfig = { theme: 'default', locale: LocaleType.KO_KR, plugins: [ [UniverDocsPlugin], [UniverSheetsPlugin, { // MSM 견적서 특화 설정 features: { conditionalFormatting: true, dataValidation: true, charts: true, realTimeCollaboration: true }, customFunctions: { 'MSM_TOTAL_CALC': (range) => { // MSM 견적서 총액 계산 커스텀 함수 return range.reduce((sum, cell) => sum + (cell.value || 0), 0); }, 'MSM_VAT_CALC': (amount, vatRate = 0.1) => { // 부가세 계산 return amount * vatRate; } } }] ] }; // 견적서 템플릿 생성 function createMSMQuotationTemplate() { return { sheets: [{ name: 'MSM 견적서', sheetId: 'quotation_sheet', cellData: { 0: { // 첫 번째 행 - 헤더 0: { v: 'MSM 의료기기 견적서', s: headerStyle }, // 병합된 셀 정보 mergeInfo: [{ startRow: 0, endRow: 0, startColumn: 0, endColumn: 5 }] }, 1: { // 두 번째 행 - 컬럼 헤더 0: { v: '품목명', s: columnHeaderStyle }, 1: { v: '수량', s: columnHeaderStyle }, 2: { v: '단가', s: columnHeaderStyle }, 3: { v: '금액', s: columnHeaderStyle }, 4: { v: '비고', s: columnHeaderStyle }, 5: { v: '상태', s: columnHeaderStyle } } } }] }; } // 스타일 정의 const headerStyle = { fontFamily: 'Arial', fontSize: 16, bold: true, backgroundColor: '#4472C4', color: '#FFFFFF', horizontalAlignment: 'center', verticalAlignment: 'middle' }; const columnHeaderStyle = { fontFamily: 'Arial', fontSize: 12, bold: true, backgroundColor: '#D5E4F7', horizontalAlignment: 'center' }; // MSM 시스템과의 데이터 동기화 async function syncWithMSMDatabase(quotationData) { const response = await fetch('/api/quotations/sync', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(quotationData) }); return response.json(); }

6. 최종 권장사항

🏆 최우선 권장: Univer + OnlyOffice CE 하이브리드

구현 방식:

  • 웹 편집: Univer (빠른 로딩, 모바일 최적화)
  • 고급 편집: OnlyOffice CE (완벽한 Excel 호환)
  • 파일 변환: 두 시스템 간 자동 동기화

예상 효과: Excel 호환성 95% + 사용자 만족도 90%

⚡ 빠른 구현: x-data-spreadsheet + ExcelJS

구현 방식:

  • 웹 편집: x-data-spreadsheet
  • 파일 출력: ExcelJS로 Excel 생성
  • 서식 적용: JavaScript로 후처리

예상 효과: 빠른 출시 + 기본 기능 충족

🎯 MSM 시스템 최종 권장안:
1단계 (즉시): x-data-spreadsheet으로 기본 기능 구현 (2-3주)
2단계 (3개월 후): Univer로 업그레이드 (고급 기능 추가)
3단계 (6개월 후): OnlyOffice CE 통합 (완벽한 Excel 호환성)
