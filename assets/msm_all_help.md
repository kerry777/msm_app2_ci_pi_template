# 전체 도움말

## 재고현황
**목적**: 대리점, 개인, 병원의 현재 재고 현황을 실시간으로 확인

- **대리점 재고**: 전체 대리점 재고 현황 및 분석 데이터 제공
- **내 재고**: 개인 담당 구역의 재고 현황 및 관리
- **병원 재고**: 병원별 재고 현황 및 부족 품목 확인
- **재고 분석**: 재고 데이터를 차트로 분석하여 인사이트 제공

**주의점**: 실시간 데이터이므로 네트워크 상태에 따라 로딩 시간 차이
**기타**: 필터링 및 검색 기능으로 원하는 데이터 빠르게 찾기 가능

## 병원재고조사
**목적**: 병원의 재고를 정기적으로 조사하여 정확한 재고 관리

- **재고조사 대시보드**: 조사가 필요한 병원을 우선순위별로 표시
- **병원재고조사 등록**: 새로운 재고조사 데이터 입력 및 저장
- **병원재고조사 수정**: 기존 조사 데이터 수정 및 업데이트
- **품목반출/반납**: 병원과 대리점 간 품목 이동 관리
- **제품납품**: 병원에 제품을 납품하는 과정 관리
- **병원별 조사주기 설정**: 각 병원의 재고조사 주기 개별 설정

**주의점**: 조사 데이터 입력 시 정확성 확인 필수
**기타**: 자동 알림 기능으로 조사 예정일 관리

## 재고마감
**목적**: 월말 재고를 정확히 마감하여 재고 정산 및 분석

- **재고마감 등록**: 월말 재고 현황을 입력하여 마감 처리
- **재고마감 이력**: 과거 마감 내역 조회 및 검증
- **재고마감 번복 요청**: 잘못된 마감 데이터 수정 요청
- **자동주문 조회**: 재고 부족 시 자동 생성된 주문 확인
- **재고마감 분석**: 마감 데이터를 분석하여 경영 지표 제공

**주의점**: 마감 후 번복이 어려우니 신중하게 진행
**기타**: 마감 전 데이터 검증 기능으로 오류 방지

## 재고분석
**목적**: 재고 데이터를 분석하여 경영 의사결정 지원

- **재고 차트**: 재고 현황을 시각적으로 분석
- **트렌드 차트**: 재고 변화 추이를 시간별로 분석
- **대시보드 차트**: 주요 지표를 한눈에 확인
- **월간 리포트**: 월별 재고 현황 및 분석 리포트
- **분기별 분석**: 분기별 재고 성과 및 트렌드 분석

**주의점**: 데이터 로딩 시간이 길 수 있음
**기타**: 다양한 차트 형태로 데이터 시각화

## 재고설정
**목적**: 재고 관리에 필요한 기본 설정 및 기준값 관리

- **대리점 월별 기초재고 등록**: 월별 기초재고 수준 설정
- **대리점 월별 기초재고 수정**: 기존 기초재고 수준 조정
- **대리점 안전재고 등록/수정**: 안전재고 수준 설정
- **병원 안전재고 등록/수정**: 병원별 안전재고 수준 설정
- **대리점 품목입고 등록/수정**: 입고 내역 관리 및 기록

**주의점**: 설정 변경 시 기존 데이터에 영향 주의
**기타**: 설정 이력 관리로 변경 사항 추적 가능

상세 기능 가이드
1. 앱 개요
   MDM 앱은 소모품 재고 관리와 제품/상품 주문을 통합한 물류 관리 솔루션입니다. 대리점과 본사의 협업을 강화하며, 병원/요양병원의 재고를 효율적으로 관리합니다.
1.1 주요 사용자
  - **대리점 영업사원**: 재고 조사, 납품, 주문 등록.
  - **본사 영업 직원**: 주문 등록 및 내역 조회.

1.2 핵심 기능
  - **소모품 재고 관리**: 대리점/병원 재고 추적, 안전 재고 관리.
  - **제품/상품 주문**: 거래처/품목 선택, 장바구니 기반 주문.
  - **주문 내역 조회**: 최근 주문 및 과거 내역 확인.
  - **추가 기능**: 즐겨찾기, 실시간 알림, 다국어 지원.

2. 로그인
   앱 실행 후 로그인 화면에서 계정에 접속하세요. 최신 버전은 빠른 로그인과 다국어 지원을 제공합니다.
2.1 로그인 방법
  - **대리점 선택**:
    - 사용자 조회 버튼 클릭.
    - 드롭다운에서 대리점 선택 (예: "아이멕시스템", "디에이치메디컬").
    - ID/비밀번호 자동 입력.
  - **빠른 로그인**:
    - 대리점별 전용 버튼 클릭.
  - **로그인**:
    - 로그인 버튼 클릭.
    - 실패 시: "아이디와 비밀번호를 확인해주세요" 메시지.

2.2 새 기능
  - **다국어 지원**: 로그인 화면에서 언어 선택 (한국어, 영어, 일본어).
  - **비밀번호 재설정**: "비밀번호 찾기" 링크로 이메일 인증.
  - **생체 인증**: 지문/얼굴 인식 로그인 (지원 기기 한정).

2.3 주의사항
  - 네트워크 연결 확인.
  - 대리점 계정은 관리자가 사전 등록 필요.
  - 문의: [support@mekics.com](mailto:support@mekics.com).

3. 소모품 재고 관리
   대리점 영업사원을 위한 소모품 재고 관리 기능은 병원/요양병원의 창고별 재고를 관리하고, 부족분을 납품하는 프로세스를 지원합니다.
3.1 재고 관리 개요
  - **대리점 재고 계산**:
    - 공식: **월별 기초재고 + 입고수량 - 출고수량**.
    - **월별 기초재고**: 매월 초 입력.
    - **입고수량**: 본사 → 대리점 납품.
    - **출고수량**: 대리점 → 병원 납품.
  - **My 현재고**:
    - 품목 반출 - 병원 납품 = My 현재고.
  - **안전 재고**:
    - 대리점/병원 창고별 기준 설정.
    - 부족 시 알림 및 납품 제안.

3.2 월별 기초재고 입력
  - **경로**: 소모품 재고 관리 → 월별 기초재고 입력.
  - **단계**:
    1. 품목 목록에서 수량 입력.
    2. **저장** 버튼 클릭.
  - **새 기능**:
    - **자동 입력 제안**: 지난달 재고 기반 추천.
    - **실시간 동기화**: 입력 즉시 대리점 현재고 갱신.
  - **주의사항**:
    - 매월 1~5일 내 입력 권장.
    - 입력 후 수정은 관리자 승인 필요.

3.3 병원 창고별 재고 조사
  - **경로**: 소모품 재고 관리 → 병원 재고 조사.
  - **단계**:
    1. 병원 선택 (즐겨찾기 사용 가능).
    2. 창고 선택 (예: 응급실, 병동).
    3. 현재고 및 안전 재고 비교.
    4. 부족 품목 납품 등록.
  - **새 기능**:
    - **즐겨찾기**: 자주 조사하는 병원/창고 저장.
    - **실시간 알림**: 재고 부족 시 푸시 알림.
    - **검색**: 병원/창고 이름으로 빠른 탐색.
  - **주의사항**:
    - 조사 전 네트워크 연결 확인.
    - 데이터 동기화 지연 시 새로고침.

3.4 품목 반출 및 납품
  - **품목 반출**:
    - **경로**: 품목 반출 메뉴.
    - **단계**:
      1. 품목 선택 및 수량 입력.
      2. **반출** 버튼 클릭.
      3. My 현재고에 반영.
  - **납품**:
    - **경로**: 병원 창고별 납품.
    - **단계**:
      1. 납품 수량 입력.
      2. My 현재고 차감.
      3. **저장** 버튼 클릭.
  - **새 기능**:
    - **자동 계산**: 납품 수량 추천.
    - **오프라인 모드**: 네트워크 없이 임시 저장.
  - **주의사항**:
    - 반출/납품 기록은 수정 불가, 관리자 문의.

3.5 안전 재고 관리
  - **경로**: 안전 재고 설정.
  - **단계**:
    1. 대리점/병원 창고 선택.
    2. 품목별 안전 재고 입력.
    3. **저장** 버튼 클릭.
  - **새 기능**:
    - **AI 예측**: 과거 데이터 기반 안전 재고 제안.
    - **알림 설정**: 부족 시 즉시 알림.
  - **주의사항**:
    - 안전 재고는 월 1회 조정 권장.
    - 변경은 관리자 승인 필요.

4. 제품/상품 주문
   제품/상품 주문 기능은 대리점과 본사 사용자가 거래처와 품목을 선택해 주문을 등록하는 프로세스를 지원합니다.
4.1 거래처 선택
  - **경로**: 제품/상품 주문 → 거래처 선택.
  - **단계**:
    1. **거래처 선택** 버튼 클릭.
    2. 팝업에서 거래처 검색 (예: "imeksys").
    3. 거래처 클릭 → 상단에 표시 (예: "imeksys (ACA026)").
    4. 초기화: **X** 버튼 클릭.
  - **새 기능**:
    - **즐겨찾기**: 자주 사용하는 거래처 저장.
    - **자동 완성**: 검색어 입력 시 제안.
  - **주의사항**:
    - 거래처 선택 전 품목 검색 불가.
    - 검색어 오타 주의.

4.2 품목 검색 및 필터링
  - **단계**:
    1. 검색창에 품번/품명/규격 입력.
    2. 필터 적용 (지역, 대/중/소분류).
    3. 필터 제거: **X** 버튼 또는 초기화.
  - **새 기능**:
    - **AI 추천**: 사용 패턴 기반 품목 제안.
    - **최근 검색어**: 저장 및 재사용.
    - **다국어 검색**: 영어/일본어 지원.
  - **주의사항**:
    - 검색 전 거래처 선택 필수.
    - 필터 조건은 최대 5개 권장.

4.3 품목 정렬
  - **옵션**:
    - 품명: 이름순.
    - 품번: 코드순.
    - 단가: 가격순.
  - **새 기능**:
    - **사용자 맞춤 정렬**: 자주 선택한 기준 우선.
  - **주의사항**:
    - 정렬은 검색 결과에만 적용.

4.4 품목 선택
  - **모드**:
    - **팝업**: 품목 클릭 → 수량 입력.
    - **다중 선택**: 체크박스 선택 → 장바구니 추가.
  - **단계**:
    1. 모드 선택 (기본: 다중 선택).
    2. 품목 선택 (팝업: 수량 입력 / 다중: 체크박스).
    3. **장바구니 담기** 클릭.
  - **새 기능**:
    - **즐겨찾기 품목**: 별 아이콘으로 빠른 추가.
    - **수량 추천**: 과거 주문 기반 제안.
  - **주의사항**:
    - 선택 품목은 거래처별로 제한될 수 있음.

4.5 장바구니 관리
  - **경로**: 장바구니 보기 (쇼핑카트 아이콘).
  - **단계**:
    1. 품목 목록 확인 (품번, 품명, 수량, 단가, 금액).
    2. 수량 수정 → 총액 자동 업데이트.
    3. 삭제: **휴지통** 아이콘 클릭.
    4. **주문 제출** 또는 **취소**.
  - **새 기능**:
    - **실시간 총액 계산**: 수량 변경 즉시 반영.
    - **주문 미리보기**: PDF 출력 지원.
  - **주의사항**:
    - 주문 제출 후 수정 불가.
    - 네트워크 연결 확인.

5. 주문 내역 조회
   과거 주문 기록을 확인하고, 품목별 재주문을 지원합니다.
5.1 최근 주문 조회
  - **경로**: 최근 주문 탭.
  - **내용**:
    - 최근 90일 주문 표시 (기존 30일 → 확장).
    - 품번, 수량, 금액, 주문일.
  - **새 기능**:
    - **필터링**: 날짜 범위, 거래처별 조회.
    - **재주문**: 품목 클릭 → 주문 화면 이동.
  - **주의사항**:
    - 오래된 주문은 아카이브 처리 가능.

5.2 전체 주문 내역
  - **경로**: 주문 내역 탭.
  - **내용**:
    - 주문번호별 목록, 확장 시 세부 품목.
  - **새 기능**:
    - **검색**: 주문번호/품목명으로 필터링.
    - **내보내기**: CSV/PDF 다운로드.
  - **주의사항**:
    - 대량 데이터 조회 시 로딩 지연 가능.
