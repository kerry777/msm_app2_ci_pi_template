# 재고마감 도움말

## 목적
월말 재고를 정확히 마감하여 재고 정산 및 분석을 통해 효율적인 재고 관리를 지원합니다.

## 주요 기능

### 재고마감 등록
- 월말 재고 현황을 입력하여 마감 처리
- 재고 수량 및 금액 정산
- 마감 일시 및 담당자 정보 기록

### 재고마감 이력
- 과거 마감 내역 조회 및 검증
- 마감 데이터 비교 분석
- 마감 이력 추적 및 관리

### 재고마감 번복 요청
- 잘못된 마감 데이터 수정 요청
- 번복 사유 및 승인 절차 관리
- 번복 이력 추적 및 기록

### 자동주문 조회
- 재고 부족 시 자동 생성된 주문 확인
- 자동주문 기준 및 조건 관리
- 주문 상태 및 진행 상황 추적

### 재고마감 분석
- 마감 데이터를 분석하여 경영 지표 제공
- 재고 성과 및 효율성 분석
- 재고 최적화를 위한 인사이트 제공

## 사용법

1. **재고마감 메뉴 선택**: 메인 화면에서 "재고마감" 메뉴를 클릭합니다.
2. **서브메뉴 선택**: 원하는 마감 기능을 선택합니다.
3. **데이터 입력/확인**: 마감 데이터를 입력하거나 기존 데이터를 확인합니다.
4. **마감 처리**: 데이터 검증 후 마감 처리를 진행합니다.

## 주의사항
- 마감 후 번복이 어려우니 신중하게 진행하세요.
- 마감 전 반드시 데이터 검증을 진행하세요.
- 중요한 마감 데이터는 승인 절차를 거쳐야 합니다.

## 기타 기능
- 마감 전 데이터 검증 기능으로 오류를 방지합니다.
- 자동 알림 기능으로 마감 예정일을 관리합니다.
- 마감 리포트 생성 및 공유 기능을 제공합니다.
