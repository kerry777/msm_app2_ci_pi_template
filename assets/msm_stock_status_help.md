# 재고현황 도움말

## 목적
대리점, 개인, 병원의 현재 재고 현황을 실시간으로 확인하고 관리합니다.

## 주요 기능

### 대리점 재고
- 전체 대리점 재고 현황 및 분석 데이터 제공
- 대리점별 재고 수준 비교 및 분석
- 재고 부족 대리점 식별 및 관리

### 내 재고
- 개인 담당 구역의 재고 현황 및 관리
- 담당 구역 내 재고 현황 실시간 모니터링
- 개인별 재고 관리 업무 지원

### 병원 재고
- 병원별 재고 현황 및 부족 품목 확인
- 병원별 재고 수준 분석 및 관리
- 병원 재고 부족 시 알림 기능

### 재고 분석
- 재고 데이터를 차트로 분석하여 인사이트 제공
- 재고 트렌드 분석 및 예측
- 재고 최적화를 위한 데이터 기반 의사결정 지원

## 사용법

1. **재고현황 메뉴 선택**: 메인 화면에서 "재고현황" 메뉴를 클릭합니다.
2. **서브메뉴 선택**: 원하는 재고 현황 유형을 선택합니다.
3. **데이터 확인**: 실시간 재고 데이터를 확인하고 분석합니다.
4. **필터링**: 필요에 따라 필터를 적용하여 원하는 데이터만 표시합니다.

## 주의사항
- 실시간 데이터이므로 네트워크 상태에 따라 로딩 시간 차이가 있을 수 있습니다.
- 데이터 새로고침이 필요한 경우 새로고침 버튼을 사용하세요.
- 재고 부족 항목은 빨간색으로 표시됩니다.

## 기타 기능
- 필터링 및 검색 기능으로 원하는 데이터를 빠르게 찾을 수 있습니다.
- 엑셀 내보내기 기능으로 데이터를 외부로 저장할 수 있습니다.
- 차트 분석 기능으로 재고 트렌드를 시각적으로 확인할 수 있습니다.
