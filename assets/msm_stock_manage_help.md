# 병원재고조사 도움말

## 목적
병원의 재고를 정기적으로 조사하여 정확한 재고 관리와 효율적인 재고 운영을 지원합니다.

## 주요 기능

### 재고조사 대시보드
- 조사가 필요한 병원을 우선순위별로 표시
- 조사 예정일 및 진행 상황 실시간 모니터링
- 조사 완료율 및 성과 지표 제공

### 병원재고조사 등록
- 새로운 재고조사 데이터 입력 및 저장
- 병원별 재고 현황 상세 기록
- 조사 일시 및 담당자 정보 관리

### 병원재고조사 수정
- 기존 조사 데이터 수정 및 업데이트
- 오류 데이터 수정 및 검증
- 조사 이력 관리 및 추적

### 품목반출/반납
- 병원과 대리점 간 품목 이동 관리
- 반출/반납 내역 추적 및 기록
- 품목 이동 승인 및 검증 프로세스

### 제품납품
- 병원에 제품을 납품하는 과정 관리
- 납품 일정 및 상태 추적
- 납품 완료 확인 및 서명 관리

### 병원별 조사주기 설정
- 각 병원의 재고조사 주기 개별 설정
- 병원별 특성에 맞는 조사 주기 최적화
- 자동 알림 및 리마인더 기능

## 사용법

1. **병원재고조사 메뉴 선택**: 메인 화면에서 "병원재고조사" 메뉴를 클릭합니다.
2. **서브메뉴 선택**: 원하는 기능을 선택합니다.
3. **데이터 입력/수정**: 필요한 데이터를 입력하거나 수정합니다.
4. **저장 및 확인**: 데이터를 저장하고 결과를 확인합니다.

## 주의사항
- 조사 데이터 입력 시 정확성을 반드시 확인하세요.
- 중요한 데이터 수정 시 승인 절차를 거쳐야 합니다.
- 조사 완료 후 데이터 검증을 필수로 진행하세요.

## 기타 기능
- 자동 알림 기능으로 조사 예정일을 관리할 수 있습니다.
- 조사 데이터 통계 및 분석 리포트를 제공합니다.
- 모바일 앱으로 현장에서 실시간 조사 데이터 입력이 가능합니다.
