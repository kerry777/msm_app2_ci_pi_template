# 재고분석 도움말

## 목적
재고 데이터를 분석하여 경영 의사결정을 지원하고 재고 최적화를 위한 인사이트를 제공합니다.

## 주요 기능

### 재고 차트
- 재고 현황을 시각적으로 분석
- 품목별 재고 수준 비교
- 재고 분포 및 집중도 분석

### 트렌드 차트
- 재고 변화 추이를 시간별로 분석
- 재고 증가/감소 패턴 파악
- 계절성 및 주기적 변화 분석

### 대시보드 차트
- 주요 지표를 한눈에 확인
- 실시간 재고 현황 모니터링
- 핵심 성과 지표(KPI) 시각화

### 월간 리포트
- 월별 재고 현황 및 분석 리포트
- 월간 재고 성과 평가
- 월별 재고 변화 추이 분석

### 분기별 분석
- 분기별 재고 성과 및 트렌드 분석
- 분기별 재고 최적화 성과 평가
- 연간 재고 계획 수립 지원

## 사용법

1. **재고분석 메뉴 선택**: 메인 화면에서 "재고분석" 메뉴를 클릭합니다.
2. **분석 유형 선택**: 원하는 분석 차트를 선택합니다.
3. **기간 및 조건 설정**: 분석 기간과 조건을 설정합니다.
4. **결과 확인**: 분석 결과를 확인하고 인사이트를 도출합니다.

## 주의사항
- 데이터 로딩 시간이 길 수 있으니 기다려주세요.
- 대용량 데이터 분석 시 시스템 성능에 영향을 줄 수 있습니다.
- 분석 결과는 참고용이며, 중요한 의사결정 시 추가 검증이 필요합니다.

## 기타 기능
- 다양한 차트 형태로 데이터를 시각화합니다.
- 분석 결과를 PDF나 엑셀로 내보낼 수 있습니다.
- 맞춤형 대시보드 설정이 가능합니다.
