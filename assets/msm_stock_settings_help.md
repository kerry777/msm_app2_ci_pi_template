# 재고설정 도움말

## 목적
재고 관리에 필요한 기본 설정 및 기준값을 관리하여 효율적인 재고 운영을 지원합니다.

## 주요 기능

### 대리점 월별 기초재고 등록
- 월별 기초재고 수준 설정
- 대리점별 특성에 맞는 기초재고 기준 설정
- 월별 기초재고 계획 수립 및 관리

### 대리점 월별 기초재고 수정
- 기존 기초재고 수준 조정
- 시장 상황 변화에 따른 기초재고 수정
- 기초재고 수정 이력 관리

### 대리점 안전재고 등록/수정
- 안전재고 수준 설정
- 품목별 안전재고 기준 관리
- 안전재고 부족 시 자동 알림 설정

### 병원 안전재고 등록/수정
- 병원별 안전재고 수준 설정
- 병원 특성에 맞는 안전재고 기준 설정
- 병원별 안전재고 관리 및 모니터링

### 대리점 품목입고 등록/수정
- 입고 내역 관리 및 기록
- 입고 품목 검증 및 승인
- 입고 이력 추적 및 관리

## 사용법

1. **재고설정 메뉴 선택**: 메인 화면에서 "재고설정" 메뉴를 클릭합니다.
2. **설정 유형 선택**: 원하는 설정 기능을 선택합니다.
3. **설정값 입력/수정**: 필요한 설정값을 입력하거나 수정합니다.
4. **저장 및 적용**: 설정을 저장하고 시스템에 적용합니다.

## 주의사항
- 설정 변경 시 기존 데이터에 영향을 줄 수 있으니 신중하게 진행하세요.
- 중요한 설정 변경 시 승인 절차를 거쳐야 합니다.
- 설정 변경 전 백업을 권장합니다.

## 기타 기능
- 설정 이력 관리로 변경 사항을 추적할 수 있습니다.
- 설정 템플릿 기능으로 빠른 설정 적용이 가능합니다.
- 설정 검증 기능으로 오류를 방지합니다.
